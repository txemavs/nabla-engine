# Recurve bow

User-provided `recurve_bow.glb`, preserved unchanged as `recurve-bow.glb`.

`game/recurve-bow-model.ts` identifies the bow, one of its three arrows and the disconnected
static string triangles. Engine clones the geometry at load time, orients and
scales the bow to 1 metre and the arrow to 62 cm, and replaces the static string
with its dynamic string. The supplied GLB is not edited. No animations were present.
