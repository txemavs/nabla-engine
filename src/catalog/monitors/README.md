# Catalog monitors

Stock layered definitions and the S3 instrument recipe. The renderer does not
know about cars.

**Owns:** `s3Instruments`, cluster artwork bindings, car menu items.
**Does not own:** GPU monitors, keyboard focus, or scene edits.
