# Catalog presentation

Model-specific adapters: lights, mounts, paint and police equipment.

**Owns:** `visual.presentation` IDs and stock asset selectors.
**Does not own:** generic mount controllers or physics.

An omitted ID means a plain model. Unknown IDs warn and omit optional equipment.
